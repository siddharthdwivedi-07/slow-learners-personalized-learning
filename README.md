# slow-learners-personalized-learning
## Features
- Student assessment through conversational questions
- AIML-based pattern matching
- Graphmaster pattern matching
- Identification of potential learning difficulties
- Area-of-concern selection
- Personalized remedial recommendations
- Online learning resources

## Technologies Used
- AIML
- Graphmaster
- Natural Language Processing
- Rule-Based System

## System Workflow
Student Input
      ↓
AIML Pattern Matching
      ↓
Learning Difficulty Assessment
      ↓
Area of Concern
      ↓
Personalized Recommendation
      ↓
Learning Resources


## How to Run
in terminal run the following:
python app.py
