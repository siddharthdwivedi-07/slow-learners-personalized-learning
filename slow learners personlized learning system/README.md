# Slow Learners Personalized Learning System

This project is a simple AIML-based learning assistant that recognizes slow learners through general questions. If the student is detected as a slow learner, the system asks for their areas of concern and provides remedial study tips. Otherwise, it gives general improvement advice.

## Files

- `main.py` - main application that runs the interactive flow.
- `aiml/slow_learners.aiml` - AIML knowledge base for responses.
- `requirements.txt` - required Python package.

## Setup

1. Create and activate a Python environment.
2. Install requirements:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python main.py
```
